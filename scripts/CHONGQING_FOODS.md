# 重庆食品参考库

当前补充84项地方食品，含豆干、苕皮及烧烤、面食、粉类、小吃、家常菜。食品名称、别名、单位重量和配方见 `utils/chongqing-data.js`，计算方法见 `utils/chongqing-foods.js`；以构建脚本为维护入口。

## 数据来源与精度

- 基础原料营养使用 USDA FoodData Central SR Legacy 2018 数据： https://fdc.nal.usda.gov/download-datasets/ 。每项原料保留 FDC ID、原名和每100克的热量、蛋白质、碳水、脂肪。
- 重庆食品名称参考重庆市农业农村委员会公开介绍： https://nyncw.cq.gov.cn/ztzl_161/rdzt/xczx/gzdt_249775/whzx/202502/t20250217_14310723_wap.html 。该资料不提供营养数值。
- 本库地方菜营养均为参考配方计算值，不是重庆菜品的实测成分表。配方公开记录原料克数、水和食用油；单位重量也是参考份量。
- 玉米淀粉代理薯类淀粉、熟意面代理熟面条、普通米粉代理糯米粉、硬豆腐代理豆制品。具体配料、含水量、油糖用量会造成偏差；不提供未有依据的微量营养素数值。
- 同名食物按不同做法区分。单位没有明确重量映射时保留待补全，不强行换算。语音别名“若皮”只在受控匹配中映射为“苕皮”。

## 模型补充

营养估算使用用户独立配置并启动的文字模型，仅发送食物名、单位和份量。未知份量要求用户补充；估算失败保留待补全项。返回值做结构、数量及能量一致性检查，但这些检查不能保证营养事实准确。估算显示为估算数据，用户核对并保存后才参与本地记录；不在后台写入未确认的食品。

## 重新生成

下载官方 SR Legacy CSV 压缩包后运行：

```text
python scripts/build-chongqing-foods.py <压缩包绝对路径>
```

运行 `node --test tests/chongqing-ai-dark.test.js` 核对条目、单位换算、截图语音及接口隔离行为。

## 名称与份量统一（2026-11-03）

去除普通牛肉面、凉面、米线、豆浆、泡菜等不必要地域前缀，保留旧名为别名。重庆小面、合川桃片等既有菜名保留。豆浆采用 USDA 175215 无糖豆浆原料，含糖版本为240克豆浆加10克糖；参考杯250克，毫升按1克的近似重量估算，不代表所有品牌实测密度。

基础库与公开成分库重合的食品共享同一份量和营养源，另补充根、个、份的显式可食重量参考；搜索去除同一食物同单位的重复项。既有用户记录及个人确认食品不自动覆盖。
